**SystemX 1.2.2**: ไอคอนล้างใหม่ และหน้าแรกนุ่มตาขึ้น · New clean icon and a softer Home

### ไทย
- **ไอคอนล้างใหม่:** ปุ่มและเมนูที่เกี่ยวกับการล้างเปลี่ยนเป็นไอคอนแปรงขัด เห็นแล้วรู้ทันทีว่าใช้ล้างเครื่อง (เมนูล้างขยะ, ปุ่มล้างด่วน, การ์ดบนหน้าแรก, หน้าล้างไฟล์ขยะ และหน้าล้างข้อมูลเครือข่าย)
- **หน้าแรก:** ลดแสงฟุ้งรอบวงแหวนคะแนนสุขภาพ ให้ดูสบายตาขึ้น

ใครใช้ 1.2.1 หรือเก่ากว่าอยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.2.2.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **New clean icon:** clean-related buttons and menus now use a cleaning-brush icon, so it's obvious what they do (Clean menu, Quick clean, the Home card, Junk cleaner and Network cleanup)
- **Home:** the glow around the health score ring is softer and easier on the eyes

If you use 1.2.1 or earlier, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.2.2.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
