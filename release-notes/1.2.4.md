**SystemX 1.2.4**: การแจ้งเตือนไม่บังปุ่มหน้าต่างแล้ว · Notifications no longer cover the window buttons

### ไทย
- **แก้ไข:** การแจ้งเตือนที่มุมขวาบน เช่น "พร้อมติดตั้งอัปเดต" เคยทับปุ่มย่อ ขยาย และปิดหน้าต่าง ตอนนี้เลื่อนลงมาแสดงใต้แถบด้านบนแล้ว กดปุ่มหน้าต่างได้ตามปกติ

ใครใช้ 1.2.3 หรือเก่ากว่าอยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.2.4.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **Fix:** notifications in the top-right corner, such as "ready to install", used to cover the minimise, maximise and close buttons. They now appear below the title bar, so the window buttons always work

If you use 1.2.3 or earlier, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.2.4.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
