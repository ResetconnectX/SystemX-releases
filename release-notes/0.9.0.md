**SystemX 0.9.0 (beta)**: เวอร์ชันทดสอบก่อน 1.0 · Beta before 1.0

### ไทย
เวอร์ชันแรกที่เปิดให้ดาวน์โหลด สำหรับทดสอบก่อนออก 1.0
- ล้างไฟล์ขยะ: สแกน ดูรายการและขนาดก่อนลบ แล้วสรุปผล
- เร่งความเร็ว: โปรแกรมเริ่มพร้อมเครื่อง (ลบแล้วกู้คืนได้), Services, Power plan, Game Mode
- ปรับแต่ง: Privacy, Explorer และแถบงาน, Visual effects, เกมและเมาส์ ทุกรายการกดเลิกทำได้ และสร้าง Restore Point ก่อนปรับแต่ง
- สุขภาพดิสก์ และตัววิเคราะห์พื้นที่ดิสก์
- เปิดพร้อม Windows ได้ โดยทำงานเบื้องหลังที่ไอคอนมุมขวาล่างของแถบงาน
- ทดสอบแล้วบน Windows 10 และ Windows 11

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
First public build, released for testing ahead of 1.0.
- Junk cleaner: scan, review the list and sizes before deleting, then see a summary
- Speed up: startup apps (removed items can be restored), services, power plans, Game Mode
- Tweaks: privacy, Explorer and taskbar, visual effects, gaming and mouse, all undoable, with a restore point first
- Disk health and disk space analyzer
- Start with Windows runs in the background from the taskbar tray icon
- Tested on Windows 10 and Windows 11

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
