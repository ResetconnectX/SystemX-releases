**SystemX 1.1.0**: หน้าใหม่ 4 หน้า ชื่อภาษาไทย และแก้บั๊กตอนเปิดพร้อม Windows · 4 redesigned pages, Thai names and start-with-Windows fixes

### ไทย
**ใหม่และปรับปรุง**
- **ล้างขยะ:** ชื่อกลุ่มไฟล์ขยะของ Windows เป็นภาษาไทยแล้ว และกลุ่มของแอป เกม และการ์ดจอมีคำอธิบายบอกว่าเป็นไฟล์อะไร
- **ความเป็นส่วนตัว:** ออกแบบใหม่ให้เหมือนหน้าปรับแต่ง มีชื่อและคำอธิบายภาษาไทยทุกรายการ เลือกหลายรายการแล้วกดใช้ทีเดียว กดเลิกทำได้ และมีปุ่ม "ป้องกันทั้งหมด"
- **Game Mode:** หน้าใหม่ มีตัวจับเวลาตอนเปิดใช้ แก้ไขรายชื่อโปรแกรมเกมได้ง่ายขึ้น และล็อกตัวเลือกไว้ระหว่างที่ Game Mode ทำงาน
- **ประวัติพื้นที่ดิสก์** และ **พื้นที่ของแอป:** หน้าตาใหม่ตามธีมของ SystemX

**แก้ไข**
- เปิดพร้อม Windows แล้วหน้าต่างเด้งขึ้นมา (ถ้าปิดครั้งก่อนตอนขยายเต็มจอ) ตอนนี้จะอยู่ที่ไอคอนถาดระบบขวาล่างตามที่ตั้งไว้
- เครื่องที่ทำงานหนักตอนเพิ่งเปิด อาจขึ้นแจ้งเตือน "บางฟีเจอร์ต้องใช้สิทธิ์ผู้ดูแลระบบ" ผิด ทำให้ Restore Point และข้อมูลดิสก์บางส่วนใช้ไม่ได้ แก้แล้ว

ใครใช้ 1.0.0 อยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.1.0.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
**New and improved**
- **Junk cleaner:** Windows junk groups now have Thai names, and app, game and GPU cache groups explain what the files are
- **Privacy:** redesigned like the Tweaks pages, with a Thai name and description for every item. Pick several, apply them at once, undo, or use "Protect all"
- **Game Mode:** new page with a session timer, easier editing of game process names, and options locked while Game Mode is on
- **Storage History** and **App Space:** refreshed in the SystemX theme

**Fixed**
- Starting with Windows showed the window if it was last closed maximized. It now stays in the system tray as intended
- On a busy machine right after sign-in, SystemX could wrongly say "Some features need administrator rights", which disabled restore points and some disk data

If you use 1.0.0, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.1.0.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
