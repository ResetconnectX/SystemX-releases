**SystemX 1.0.0**: เวอร์ชันเสถียรแรก · First stable release

### ไทย
ฟีเจอร์เหมือน 0.9.0 (beta) ทุกอย่าง ทดสอบการติดตั้ง การอัปเดตอัตโนมัติจาก 0.9.0 และการถอนการติดตั้งบน Windows 10 และ Windows 11 แล้ว
- **เปลี่ยน:** อัปเดตที่ดาวน์โหลดเสร็จจะติดตั้งตอนปิดโปรแกรม ไม่รีสตาร์ตเองกลางคันอีก และมีปุ่ม "รีสตาร์ตตอนนี้" ให้กดถ้าต้องการติดตั้งทันที (ติดตั้งใหม่ได้ค่านี้เลย ส่วนคนที่อัปเดตจาก 0.9.0 ปิดได้ที่ ตั้งค่า → "เริ่มระบบใหม่อัตโนมัติสำหรับการอัปเดต")
- ใครใช้ 0.9.0 อยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** หรือดาวน์โหลดอัตโนมัติถ้าเปิดไว้
- ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.0.0.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
Same features as 0.9.0 (beta). Installing, updating automatically from 0.9.0 and uninstalling were tested on Windows 10 and Windows 11.
- **Changed:** downloaded updates now install when you close SystemX instead of restarting it mid-task, with a "Restart now" button if you want it right away (new installs get this by default; if you update from 0.9.0, turn off Settings → "Auto-restart for updates")
- If you use 0.9.0, the update appears under **Settings → About**, or downloads automatically if that is turned on
- New install: download `SystemX-Setup-1.0.0.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
