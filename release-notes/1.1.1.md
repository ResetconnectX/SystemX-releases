**SystemX 1.1.1**: ปรับหน้าแรกตอนกำลังโหลด · Smoother loading on the home page

### ไทย
- **คะแนนสุขภาพ:** ระหว่างคำนวณคะแนน วงแหวนจะมีเส้นสแกนหมุนแทนวงว่าง และแสงเรืองรอบวงแหวนไม่ถูกตัดเป็นสี่เหลี่ยมอีก
- **การ์ด CPU / หน่วยความจำ / ดิสก์:** ระหว่างรอค่าแรกจะขึ้น "กำลังตรวจ…" แทน "อ่านค่าไม่ได้" ข้อความ "อ่านค่าไม่ได้" จะขึ้นเฉพาะเมื่ออ่านค่าไม่สำเร็จจริง

ใครใช้ 1.1.0 หรือ 1.0.0 อยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.1.1.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **Health score:** while the score is being worked out, the ring shows a spinning scan instead of an empty circle, and its glow is no longer clipped into a square
- **CPU, memory and disk cards:** they say "Checking…" while the first reading loads instead of "Unavailable", which now only appears when a reading really fails

If you use 1.1.0 or 1.0.0, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.1.1.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
