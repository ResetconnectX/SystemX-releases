**SystemX 1.2.0**: ทุกหน้าหน้าตาใหม่ · Every page gets the new look

### ไทย
- **ทุกหน้าเป็นธีม Cyan HUD แล้ว:** ตั้งค่า, ศูนย์กู้คืน, ถอนการติดตั้ง, ลบแอปที่ติดมากับเครื่อง, ไฟล์ขนาดใหญ่, ไฟล์ซ้ำ, โฟลเดอร์ว่าง, ตรวจโฟลเดอร์ Downloads, ล้างเมนูคลิกขวา, ประสิทธิภาพเครื่อง, Services, ล้าง Registry, ไดรเวอร์, กำหนดการ, ทำลายไฟล์, ล้างข้อมูลเครือข่าย, บำรุงรักษาดิสก์, ซ่อมแซม Windows และ Firewall
- **บอกชัดก่อนลงมือ:** ทุกหน้าที่ลบหรือเปลี่ยนค่าจะบอกว่าย้อนกลับได้หรือไม่ และย้อนกลับจากที่ไหน เช่น ถังรีไซเคิล หรือศูนย์กู้คืน
- **ไฟล์ขนาดใหญ่ / ไฟล์ซ้ำ:** กรองตามชนิดไฟล์ได้ และไฟล์ซ้ำมีป้าย "เก็บไว้" กับ "จะลบ" ชัดเจน
- **เมนูคลิกขวา:** เปิด/ปิดแต่ละรายการด้วยสวิตช์ และลบแล้วรายการหายจากหน้าทันที
- **แก้ไข:**
  - วันที่ติดตั้งบางโปรแกรมแสดงผิด
  - เปิดหน้าใหม่แล้วเลื่อนลงไปเอง
  - ตอนหน้าต่างแคบ เมนูย่อยค้างทับเนื้อหา
  - ข้อความภาษาอังกฤษที่หลุดมาบางจุด
  - ข้อความ "RESET X" ที่ค้างอยู่ในหน้ากำหนดการ

ใครใช้ 1.1.1 หรือเก่ากว่าอยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.2.0.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **Every page now uses the Cyan HUD theme:** Settings, Recovery Centre, Uninstaller, Debloater, Large files, Duplicates, Empty folders, Downloads review, Context menu cleaner, Performance, Services, Registry cleaner, Drivers, Schedules, File shredder, Network cleanup, Disk maintenance, Windows repair and Firewall
- **Clear before you act:** every page that deletes or changes something says whether it can be undone and where (Recycle Bin or Recovery Centre)
- **Large files / Duplicates:** filter by file type, and duplicates are clearly marked "Keep" or "Delete"
- **Context menu:** turn each entry on or off with a switch, and removed entries disappear from the list right away
- **Fixes:** wrong install dates for some programs, pages opening part-way scrolled, the sidebar submenu covering content in small windows, some untranslated text, and a leftover "RESET X" in Schedules

If you use 1.1.1 or earlier, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.2.0.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
