**SystemX 1.2.5**: ไอคอนบนเดสก์ท็อปเปลี่ยนทันทีหลังอัปเดต · Shortcut icons refresh right after an update

### ไทย
- **แก้ไข:** หลังอัปเดต ไอคอน SystemX บนเดสก์ท็อปและ Start menu บางเครื่องยังเป็นรูปเก่าจนกว่าจะรีสตาร์ต ตอนนี้ตัวติดตั้งสั่งให้ Windows รีเฟรชไอคอนให้ทุกครั้งที่ติดตั้งหรืออัปเดตเสร็จ

ถ้าไอคอนยังเป็นรูปเก่าจากรุ่น 1.2.3–1.2.4 อยู่ การอัปเดตเป็นรุ่นนี้จะรีเฟรชให้ หรือจะรีสตาร์ตเครื่องก็ได้

ใครใช้ 1.2.4 หรือเก่ากว่าอยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.2.5.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **Fix:** after an update, the SystemX icon on the Desktop and in the Start menu could keep showing the old picture until a restart. The installer now tells Windows to refresh its icons every time it installs or updates

If your icon still shows the old picture from 1.2.3–1.2.4, updating to this version refreshes it, or you can restart your PC

If you use 1.2.4 or earlier, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.2.5.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
