**SystemX 1.2.3**: โลโก้ใหม่ · A new logo

### ไทย
- **โลโก้ใหม่:** ตัว X ที่ขาข้างหนึ่งเป็นแปรงกวาด บอกว่า SystemX ช่วยกวาดเครื่องให้สะอาด ใช้ทั้งไอคอนโปรแกรม แถบงาน ไอคอนข้างนาฬิกา ตัวติดตั้ง และในหน้าแอป
- **คมทุกขนาด:** ไอคอนขนาดเล็กบนแถบงานและข้างนาฬิกาใช้แบบที่ตัดรายละเอียดออก จึงยังเห็นชัดแม้ย่อเล็ก

หลังอัปเดต ไอคอนบนเดสก์ท็อปหรือ Start menu อาจยังเป็นรูปเก่าอยู่สักพักจนกว่า Windows จะรีเฟรชไอคอน ถ้ายังไม่เปลี่ยน ลองรีสตาร์ตเครื่อง

ใครใช้ 1.2.2 หรือเก่ากว่าอยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.2.3.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **New logo:** an X with one stroke shaped like a sweeping brush, because SystemX sweeps your PC clean. It is used for the app icon, the taskbar, the tray icon, the installer and inside the app
- **Sharp at every size:** the small taskbar and tray icons use a simplified version, so they stay clear even when tiny

After updating, the desktop or Start menu icon may show the old picture for a while until Windows refreshes its icons. If it does not change, restart your PC.

If you use 1.2.2 or earlier, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.2.3.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
