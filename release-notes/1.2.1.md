**SystemX 1.2.1**: ธีมกลางคืนโทนดำอมเทา · A cleaner dark theme

### ไทย
- **ธีมกลางคืนใหม่:** เปลี่ยนจากโทนน้ำเงินกรมท่าเป็นดำอมเทา ดูสบายตาขึ้น สีเน้นยังเป็นฟ้าเหมือนเดิม
- **พื้นหลังเรียบขึ้น:** เอาเส้นตารางที่อยู่หลังทุกหน้าออก
- **หน้าแรก:** เอากราฟิกจุดเชื่อมเส้นที่เคลื่อนไหวอยู่หลังคะแนนสุขภาพออก หน้าแรกจึงใช้เครื่องน้อยลงเล็กน้อย

ใครใช้ 1.2.0 หรือเก่ากว่าอยู่ จะได้รับอัปเดตนี้ผ่านหน้า **ตั้งค่า → เกี่ยวกับ** (ติดตั้งตอนปิดโปรแกรม) · ติดตั้งใหม่: ดาวน์โหลด `SystemX-Setup-1.2.1.exe` ด้านล่าง

ยังไม่ได้เซ็นโปรแกรม Windows SmartScreen จะเตือน ให้กด **More info → Run anyway** (ดูวิธีใน README)

### English
- **New dark theme:** switched from navy to a neutral graphite that's easier on the eyes; the cyan accent stays
- **Cleaner background:** removed the grid lines behind every page
- **Home:** removed the animated dot-and-line graphic behind the health score, so Home does a little less work

If you use 1.2.0 or earlier, the update appears under **Settings → About** and installs when you close SystemX · New install: download `SystemX-Setup-1.2.1.exe` below

Not code-signed yet: Windows SmartScreen will warn. Choose **More info → Run anyway** (see the README).
